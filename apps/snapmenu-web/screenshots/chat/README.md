# Friends and chats at 390 × 844

Two isolated Chromium profiles registered passkeys and used the same local Worker and D1 database. The camera test fed the first phone’s rendered QR into the second phone’s video stream and decoded it with bundled jsQR. The voice test recorded and played audio using Chromium’s simulated microphone.
