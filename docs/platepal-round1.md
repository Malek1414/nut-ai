## Filming flows

All screenshots below are 390×844, captured and reviewed after the layout iteration. The smoke run used independent mobile browser contexts, simulated browser speech results, local Worker/D1, a local Anthropic fixture for the menu photo and OpenFreeMap basemap tiles. The run also checked typing without speech support, Instagram onboarding, joining and leaving the Premium interest list, menu chat, and the 18+ drink gate. No live Anthropic requests or paid services were used for verification.

**Before filming:** do a physical-device mic and camera check on the HTTPS site in Safari or Chrome. Built-in recognition and permissions depend on the browser; Instagram's embedded browser may require opening the link in the system browser. Type when speech is blocked. Use a restaurant with a previously scanned, attached menu for real nearby picks. The Berlin Mitte examples are illustrative, labeled, and not current menus; don't present them as verified restaurant data. Solo voice matches recognized goals, diets, allergen hints and euro budgets, not arbitrary requests about a kitchen. Check the “Matched on” line; confirm allergen and ingredient information with staff. With no local menu coverage, scan or try the explicit Berlin preview. Table scans still use the app's existing Anthropic menu reader, but don't request a second AI pass for ordering tips.

**Money rule:** no server speech service, Google Maps/Places, new AI provider or paid add-on. Maps use MapLibre, OpenFreeMap and OpenStreetMap data. Only the existing Anthropic configuration is used for model calls. Nut AI credit and AGPL terms are unchanged.
